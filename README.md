# 频率编曲器 Frequency Music Composer

一个零门槛的浏览器端编曲工具——用纯数字（频率 + 时间）直接谱曲，无需任何音乐理论基础。

## 演示

在线地址：<https://free-compose-tool.vercel.app/>。编曲器仍可离线使用；作品社区需要HTTP服务和Neon数据库。

## 作品社区

- 从工作台发布乐谱、逐音符音色、音量、标题和创作介绍
- 浏览、搜索、试听、点赞、评论，复制作品链接
- 导入社区作品继续编曲，导入前会提醒保存当前作品
- 账号密码注册和登录，跨设备管理自己的作品和评论；浏览、试听和本地编曲无需登录
- 乐谱存储在Neon Postgres，通过Vercel Functions访问；浏览器不会获得数据库密钥
- 每首作品最多512个音符、4分钟（240秒，含上限）；试听复用工作台的音色合成模型

发布、评论、点赞和举报需要登录。账号为3–24位字母、数字或下划线（不区分大小写），密码为10–128个字符。Better Auth负责加盐scrypt哈希和数据库会话，密码不会明文保存。登录有效期7天；修改密码会撤销其他设备的会话，退出会立即撤销当前会话。

同一IP在滚动24小时内最多注册3个账号；IPv6按/64网段计数。注册额度用数据库事务和锁保障，登录尝试也在数据库中限频。IP限制可以抑制批量注册，不能代替真实身份验证；共享网络会共享额度。IP限流键保存为HMAC摘要，原始IP不写入账号数据库。

无需手机或邮箱，不发送短信，也不提供忘记密码找回。请使用密码管理器。旧版访客可在原浏览器登录后，从“我的账号”认领旧作品和评论；仅凭昵称不能认领，清除旧Cookie后无法认领。未认领的旧内容仍可在原浏览器退出账号后撤回。上传到波形查看器的音频文件仍在浏览器本地，不会发布到社区。

### 本地开发与部署

需要Node.js 24及以上版本。

```sh
npm ci
# 将 .env.example 复制为 .env.local，设置自己的 DATABASE_URL
# 用随机生成的至少32字符密钥填写 BETTER_AUTH_SECRET（不要提交到仓库）
# BETTER_AUTH_URL 本地为 http://localhost:3000，线上为正式站点地址
npm run db:migrate
npm run dev
```

在Vercel项目中连接Neon并配置`DATABASE_URL`和服务端Secret `BETTER_AUTH_SECRET`，再部署仓库。预览和正式环境使用不同的随机密钥。首次请求会创建`composer_`前缀的社区和认证数据表；认证表迁移由数据库锁串行保护。构建只公开`index.html`、`forum.js`、`forum.css`、`score-model.js`和`accounts.js`，后端源码和环境文件不会进入静态输出。公开认证接口仅允许注册、登录、查询当前账号、退出、改密码和认领；不公开认证库的其他路由。

```sh
npm run build
npm test
# 用独立测试账号验证预览/正式环境，测试作品会在结束时撤回
# 凭据JSON为 {"owner":{"username":"...","password":"..."},"other":{"username":"...","password":"..."}}
# 仅第一次注册测试账号时设置 TEST_REGISTER_ACCOUNTS=1；会计入IP注册额度
FORUM_BASE_URL=https://your-deployment.vercel.app TEST_ACCOUNTS_FILE=./work/test-accounts.json npm run test:integration
```

### 管理与数据

作品和评论撤回采用软删除。用户可以举报作品，记录保存在`composer_reports`，当前需维护者在数据库中查看并处理（这一版不包含管理后台）。数据库采用参数化查询；社区用户文本以纯文本渲染。写入须同源JSON请求，发布和互动按账号及来源IP限制频率。只有Vercel覆盖的来源IP头用于账号限流；本地开发统一使用本地额度。

备份和恢复通过Neon控制台管理。预览和正式环境连接同一数据库时会共享社区内容；自动验证创建的临时作品与评论会撤回，但软删除记录仍保留。

## 使用方法

每个音符由三个数字定义：

| 参数 | 说明 | 示例 |
|------|------|------|
| **频率 (Hz)** | 音高，如 440 = A4 | `262` = C4（中央 C） |
| **开始时间 (s)** | 该音符何时开始播放 | `0` = 第 0 秒 |
| **持续时间 (s)** | 播放多长时间 | `0.5` = 半秒 |

多个音符设置相同的开始时间即可形成**和弦**。

每一行可以从下拉菜单选择13种音色之一。不同乐器的音符可以重叠或交替演奏。顶部的“新增音符默认音色”只作用于之后添加的音符；“将默认音色应用于所有音符”可以统一已有音符。复制音符会保留原音色。

### 快速上手

1. 打开页面，点击任意预设（如「小星星」）试听
2. 在音符列表中修改数字，或点击「添加音符」新增
3. 需要在中间补音符时，点击任意一行的“前插”或“后插”，填写新音符的频率、开始时间和持续时间；原有音符的时间不变
4. 点击 ▶ 播放 收听效果
5. 满意后点击 ⬇ 导出 WAV 保存为音频文件

## 功能

- **13 种音色**：原声钢琴、电钢琴、拨弦吉他、八音盒、马林巴、风琴、弦乐、氛围铺底、长笛，以及 4 种基础波形
- **逐音符音色**：实时播放、WAV混音、JSON和作品社区都保留每个音符的乐器，导出包含各乐器完整的释放尾音
- **动态音色合成**：使用多层泛音、自然起音与衰减包络，让不同乐器具有明显的听感差异
- **音色一致导出**：实时播放与 WAV 导出使用同一套合成模型
- **音频波形查看器**：上传浏览器支持的音频文件，在本地解码并绘制自动增益校准的分段 RMS 能量柱，支持 1×–24× 时间缩放、位置导航、播放自动跟随和点击跳转
- **交互时间线**：根据音符长度与窗口宽度自动缩放，保证常见短音符清晰可见；长曲分段显示，可手动缩放、拖动查看位置，播放时自动跟随。点击时间线或拖动播放进度后松手，从选中时间开始播放，支持暂停继续及长音、尾音衔接。键盘方向键跳转，Shift 加方向键跳转10秒，空格暂停/继续；Ctrl/⌘加滚轮以鼠标位置为中心缩放
- **音符定位**：时间线音符块显示对应的列表编号，点击后暂停并滚动到该行，高亮编号且聚焦频率输入框；重叠音符重复点击轮流选择。空白处点击和拖动仍用于跳转播放，插入空行也不会导致编号错位
- **WAV 导出**：生成可下载的标准音频文件
- **BPM 时长刻度**：三种模式共用可选 BPM（默认留空）；留空时按秒编辑，最短时长和调整步长为 0.01 秒，快速简谱每音 0.5 秒。填入 BPM 后，持续时间最小值和上下键 / 调节按钮步长均为 1/4 拍（15 ÷ BPM 秒）。确认手输值时补足下限，修改有效 BPM 会补足已有过短音符，清空 BPM 保留已有音符，其余时长不按比例变速；导入保留原时长，后续编辑应用当前下限
- **新手简谱模式**：选择 12 个大调之一（默认 1=C4），复制高低音带点数字，或用撇号 / 逗号表示升降八度；连续输入 12345 可按所选 BPM 在末尾追加，每个数字一拍。支持 1–7、升降号、上下两组点及空格 / 小节线分隔，选调保留已有音高
- **频率 / 音名模式**：音高栏可输入 Hz 或音名（A4、C#4、Db4，省略八度默认 4），回车或失焦后自动按模式显示；A4 = 440 Hz，音名显示最近半音，切换模式保留原始频率，JSON / WAV / 社区保持兼容
- **JSON 导入/导出**：选择本地 JSON 文件直接导入（最大 1 MB，仅在浏览器内读取），也可粘贴编辑；格式错误不会覆盖当前编曲
- **5 个内置预设**：小星星、C 大调音阶、欢乐颂、和弦演示、卡农片段
- **频率参考表**：C3–B6 共 48 个音的频率，点击即复制

## JSON 格式

乐谱可通过 JSON 数组描述，方便程序化生成：

```json
[
  { "freq": 440, "start": 0, "dur": 0.5, "timbre": "piano" },
  { "freq": 523.25, "start": 0, "dur": 1.0, "timbre": "strings" },
  { "freq": 659.25, "start": 0.5, "dur": 0.5, "timbre": "guitar" },
  { "freq": 783.99, "start": 1.0, "dur": 1.0, "timbre": "flute" }
]
```

没有`timbre`的旧音符继承乐谱原来的全局音色。JSON导入也接受`{notes: [...], timbre: "guitar", volume: 0.6}`这种全局乐谱对象。旧版纯数组没有保存全局音色时，会使用导入时工作台选中的默认音色；导入后各音符的音色固定下来。JSON导出仍采用音符数组格式。

## 技术栈

- 浏览器端原生 HTML + CSS + JavaScript，Web Audio编曲核心无需框架
- Vercel Functions + Neon Postgres；Better Auth账密认证和会话管理
- Web Audio API 实时合成（加法合成 + 动态包络 + 压缩保护）
- Canvas 时间线绘制

## 本地简谱图片识别（试用）

`npm run build` 构建 Dolce 浏览器识别模块，连同 OCR 模型和 ONNX WASM 一起输出到 `public/omr`。`npm run dev` 前先运行构建。模型同站点提供，不依赖第三方 CDN 或付费 API；识别在用户浏览器执行，首次加载约 40 MB。上游版本及许可证见 `vendor/dolce/README.md`。

支持单旋律印刷 PNG/JPEG/WebP、音级/八度/升降、减时线、附点、增时线、休止及可精确表示的连音时值。每四分音符 6720 tick；先按小节校验并逐小节人工确认，再转换现有 `freq/start/dur/timbre` 数组。小节总长相等不能证明每音正确；没有声明任何节奏识别准确率或零错误保证。可补入/删除音符、修改时值；弱起/末尾不完全小节可显式设置目标长度。漏识小节线应重新裁图识别。

目前发现反复、房号、跳转、跨音延音、变拍、倚音、延长记号、装饰音、多声部或小调标记时阻止导入。请先在专业乐谱编辑器中展开/处理这些内容。未检测到的符号仍需人工对照完整原图检查。替换编曲前可用原有 JSON 导出保存现有作品。

测试：`npm test`。`tests/fixtures/omr-four-quarters.png` 是自行生成的四个四分音符测试谱，不是准确率基准；真实扫描谱仍需更多样本验证。
