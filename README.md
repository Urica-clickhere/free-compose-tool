# 频率编曲器 Frequency Music Composer

一个零门槛的浏览器端编曲工具——用纯数字（频率 + 时间）直接谱曲，无需任何音乐理论基础。

## 演示

在线地址：<https://free-compose-tool.vercel.app/>。编曲器仍可离线使用；作品社区需要HTTP服务和Neon数据库。

## 作品社区

- 从工作台发布乐谱、音色、音量、标题和创作介绍
- 浏览、搜索、试听、点赞、评论，复制作品链接
- 导入社区作品继续编曲，导入前会提醒保存当前作品
- 昵称发布，无需注册；原浏览器可撤回自己的作品和评论
- 乐谱存储在Neon Postgres，通过Vercel Functions访问；浏览器不会获得数据库密钥
- 每首作品最多512个音符、120秒；试听复用工作台的音色合成模型

作品归属由HttpOnly访客Cookie确定。换设备或清除网站数据后无法管理原有内容；这一版不包含跨设备账号。上传到波形查看器的音频文件仍在浏览器本地，不会发布到论坛。

### 本地开发与部署

需要Node.js 24及以上版本。

```sh
npm ci
# 将 .env.example 复制为 .env.local，设置自己的 DATABASE_URL
npm run db:migrate
npm run dev
```

在Vercel项目中连接Neon并配置`DATABASE_URL`，再部署仓库。首次请求会创建`composer_`前缀的社区数据表。构建只公开`index.html`、`forum.js`和`forum.css`，后端源码和环境文件不会进入静态输出。

```sh
npm run build
npm test
# 指向待验证的预览或正式环境，临时测试作品会在结束时撤回
FORUM_BASE_URL=https://your-deployment.vercel.app npm run test:integration
```

### 管理与数据

作品和评论撤回采用软删除。用户可以举报作品，记录保存在`composer_reports`，当前需维护者在数据库中查看并处理（这一版不包含管理后台）。数据库采用参数化查询；社区用户文本以纯文本渲染。写入须同源请求，发布和互动按访客及来源IP限制频率。

备份和恢复通过Neon控制台管理。预览和正式环境连接同一数据库时会共享社区内容；自动验证创建的临时作品与评论会撤回，但软删除记录仍保留。

## 使用方法

每个音符由三个数字定义：

| 参数 | 说明 | 示例 |
|------|------|------|
| **频率 (Hz)** | 音高，如 440 = A4 | `262` = C4（中央 C） |
| **开始时间 (s)** | 该音符何时开始播放 | `0` = 第 0 秒 |
| **持续时间 (s)** | 播放多长时间 | `0.5` = 半秒 |

多个音符设置相同的开始时间即可形成**和弦**。

### 快速上手

1. 打开页面，点击任意预设（如「小星星」）试听
2. 在音符列表中修改数字，或点击「添加音符」新增
3. 点击 ▶ 播放 收听效果
4. 满意后点击 ⬇ 导出 WAV 保存为音频文件

## 功能

- **13 种音色**：原声钢琴、电钢琴、拨弦吉他、八音盒、马林巴、风琴、弦乐、氛围铺底、长笛，以及 4 种基础波形
- **动态音色合成**：使用多层泛音、自然起音与衰减包络，让不同乐器具有明显的听感差异
- **音色一致导出**：实时播放与 WAV 导出使用同一套合成模型
- **音频波形查看器**：上传浏览器支持的音频文件，在本地解码并绘制自动增益校准的分段 RMS 能量柱，支持 1×–24× 时间缩放、位置导航、播放自动跟随和点击跳转
- **时间线可视化**：实时显示音符分布，播放时带动画指针
- **WAV 导出**：生成可下载的标准音频文件
- **JSON 导入/导出**：保存和分享你的乐谱
- **5 个内置预设**：小星星、C 大调音阶、欢乐颂、和弦演示、卡农片段
- **频率参考表**：C3–B6 共 48 个音的频率，点击即复制

## JSON 格式

乐谱可通过 JSON 数组描述，方便程序化生成：

```json
[
  { "freq": 262, "start": 0, "dur": 0.4 },
  { "freq": 294, "start": 0.5, "dur": 0.4 },
  { "freq": 330, "start": 1.0, "dur": 0.4 }
]
```

## 常用频率速查

| 音名 | C | D | E | F | G | A | B |
|------|---|---|---|---|---|---|---|
| **第 4 octave** | 262 | 294 | 330 | 349 | 392 | 440 | 494 |

## 技术栈

- 纯 HTML + CSS + JavaScript，单文件，零依赖
- Web Audio API 实时合成（加法合成 + 动态包络 + 压缩保护）
- Canvas 时间线绘制
